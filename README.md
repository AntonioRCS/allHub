# allHub

Portfólio de Antônio Ricardo (React + Vite), publicado no GitHub Pages.

## Scripts

- `npm install` instala as dependências
- `npm run dev` roda localmente
- `npm run build` gera a pasta `dist`
- `npm run deploy` publica no GitHub Pages (branch `gh-pages`)

## GitHub Pages

1. O `base` em `vite.config.js` e o `homepage` em `package.json` já apontam para `/allHub/`.
2. Rode `npm run deploy`.
3. No GitHub: Settings > Pages > Source: branch `gh-pages` / root.

## Onde editar o conteúdo

Tudo fica em `src/data/` (experiências, tecnologias, projetos, contato).
